Added a *cooperative_setattr* option to `@attr.s` / `attrs.define`. When enabled, the generated ``__setattr__`` forwards assignments through ``super().__setattr__`` instead of writing them directly, so non-*attrs* layers can participate in the same write chain and only the class that declares an attribute runs its hook. Hooks or chain layers can now raise `attrs.setters.DeferredAssignment` to suspend an assignment without changing the current value; the nearest cooperative class arms it with a `resume()` continuation that may be invoked later, optionally with a confirmed value.
