Added an experimental tombstone mode for shrinking `Array.resize`. Pass
`mode=zarr.core.array.ResizeMode.tombstone` (or `mode="tombstone"`) with the array's
store wrapped in `zarr.experimental.manifest.ManifestStore` to hide chunks outside the
new shape through a versioned manifest instead of deleting them. Hidden chunks read as
missing, so growing the array back over the same coordinates no longer resurrects stale
bytes; their storage is reclaimed separately via `ManifestStore.reclaim`, which never
removes a chunk written after the shrink. Manifest commits use an atomic
compare-and-swap on stores implementing the new
`zarr.abc.store.SupportsVersionedReplace` protocol and fall back to ordinary writes
otherwise, leaving the existing delete/preserve resize semantics on plain stores
unchanged.
